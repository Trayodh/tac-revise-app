# Ratios & Proportions If a:b = c:d → ad = bc Fourth proportional: a:b = c:x → x = bc/a Mean proportional: a:x = x:b → x = √(ab) Compound ratio: (a:b) × (c:d) = ac:bd # Averages Average = Sum of observations / Number of observations If average of n numbers = A, and one number x is added: new avg = (nA + x)/(n+1) Weighted average = Σ(wᵢxᵢ) / Σwᵢ # Mixture & Alligation Alligation rule: cheaper:dearer = (dearer price - mean) : (mean - cheaper price) # Averages Shortcut If avg of first n natural numbers = (n+1)/2 Sum of first n natural numbers = n(n+1)/2 Sum of squares = n(n+1)(2n+1)/6 Sum of cubes = [n(n+1)/2]²
