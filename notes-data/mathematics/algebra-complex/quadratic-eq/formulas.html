# Standard Form ax^2 + bx + c = 0 where a ≠ 0 # Roots (Sridharacharya Formula) x = [-b ± √(b² - 4ac)] / 2a # Discriminant D = b² - 4ac D > 0 : Two real, distinct roots D = 0 : Two real, equal (repeated) roots D < 0 : Two complex conjugate roots # Sum & Product of Roots (α, β) Sum α + β = -b/a Product αβ = c/a Equation from roots: x² - (α+β)x + αβ = 0 # Vertex of Parabola x-coordinate of vertex = -b / 2a Min value (a > 0) = c - b²/4a = -D/4a
