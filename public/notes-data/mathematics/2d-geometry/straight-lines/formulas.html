# Forms of Equation of Line Slope-Intercept: y = mx + c Point-Slope: y - y1 = m(x - x1) Two-Point: (y-y1)/(y2-y1) = (x-x1)/(x2-x1) Intercept Form: x/a + y/b = 1 # Slope m = (y2 - y1)/(x2 - x1) = tan θ # Angle Between Two Lines tan θ = |m1 - m2| / |1 + m1·m2| Parallel: m1 = m2 Perpendicular: m1 · m2 = -1 # Distance Formulas Distance from point (x1,y1) to line ax+by+c=0: d = |ax1 + by1 + c| / √(a² + b²) Distance between parallel lines ax+by+c1=0 and ax+by+c2=0: d = |c1 - c2| / √(a² + b²)
