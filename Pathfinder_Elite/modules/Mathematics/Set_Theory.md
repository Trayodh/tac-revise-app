  - **Infinite set:** A set with an infinite number of elements.
- **Basic set operations:**
  - **Union (U):** The union of two sets A and B, denoted by A ∪ B, is the set of all elements in A or B or both.
  - **Intersection (∩):** The intersection of two sets A and B, denoted by A ∩ B, is the set of all elements common to both A and B.
  - **Difference (A/B or A - B):** Difference of A and B is the set of elements found in A but not in B.
  - **Complement (A'):** The complement of a set A, denoted by A', is the set of elements not in A.

**Page 2: Set Operations**

- **Properties of set operations:**
  - **Commutative property:** A ∪ B = B ∪ A, A ∩ B = B ∩ A
  - **Associative property:** (A ∪ B) ∪ C = A ∪ (B ∪ C), (A ∩ B) ∩ C = A ∩ (B ∩ C)
  - **Distributive property:** A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C), A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)

**Page 3: Power Sets and Cartesian Products**

- **Power set:** The power set of a set A, denoted by P(A), is the set of all subsets of A, including the empty set and A itself.
- **Cartesian product:** The Cartesian product of two sets A and B, denoted by A × B, is the set of all ordered pairs of elements from A and B.
