**Synonyms Revision Notes**

**Page 1: Introduction and Theory**

1. **Understanding Synonyms**
   - A synonym is a word or phrase that has the same or nearly the same meaning as another word or phrase.
   - Synonyms are used in language to convey the same meaning without repeating the same words.

2. **Types of Synonyms**
   - Absolute synonyms: e.g., hot, scorching, sweltering (all have the same meaning)
   - Partial synonyms: e.g., big, large, enormous (have similar meanings but subtle differences)

3. **Identifying Synonyms**
   - Analyzing sentence context
   - Using dictionaries to find alternative words
   - Considering connotations and nuances

**Page 2: Common Synonyms for Adjectives**

1. **Adjectives for Big Size**
   - Large → vast, extensive, enormous
   - Small → tiny, miniature, compact
   - Old → ancient, elderly, venerable

2. **Adjectives for Strong Sense**
   - Happy → joyful, delighted, thrilled
   - Angry → furious, enraged, enraged
   - Sad → unhappy, sorrowful, melancholic

3. **Adjectives for Emotions**
   - Love → affection, fondness, attachment
   - Hate → loathe, despise, detest
   - Fear → dread, apprehension, anxiety

**Page 3: Common Synonyms for Verbs**

1. **Action Verbs**
   - Run → sprint, dash, hurry
   - Work → labor, toil, exert oneself
   - Read → study, peruse, devour

2. **Emotional Verbs**
   - Laugh → giggle, chuckle, snicker
   - Cry → weep, sob, wail
   - Think → reflect, ponder, consider

3. **Communication Verbs**
   - Say → tell, utter, articulate
   - Speak → converse, discuss, debate
   - Listen → hear, attend, heed
